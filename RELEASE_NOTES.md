# Release Notes

## v0.1.0 - Free GitHub Foundation

Initial public foundation release.

Includes:

- `top-conference-paper-workbench` Codex skill
- top-conference paper workflow
- evidence matrix and extraction templates
- protocol and draft skeleton templates
- QA gate reference
- smoke test script
- optional PubMed helper for biomedical topics
- Word skill manual

Known limits:

- Does not include premium venue-specific templates.
- Does not include private case studies.
- Does not replace measured experiments or expert review.
- Does not guarantee paper acceptance.
